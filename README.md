# ChelsPortfolio

Portfolio site for Chels Zheng.

**Live URL:** [https://czheng987.github.io/UIUX_Portfolio/](https://czheng987.github.io/UIUX_Portfolio/)

Optional custom URL after renaming the repo on GitHub: [https://czheng987.github.io/ChelsPortfolio/](https://czheng987.github.io/ChelsPortfolio/)

## Always-on hosting (any device)

The Cursor **Live Server** preview only runs on your computer while the editor is open. To reach the site from a phone, tablet, or another computer at any time, use **GitHub Pages** (free, always on).

### One-time setup on GitHub

1. Open [github.com/czheng987/UIUX_Portfolio/settings/pages](https://github.com/czheng987/UIUX_Portfolio/settings/pages).
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push to the `main` branch. The workflow in `.github/workflows/pages.yml` publishes the site automatically.

After the first successful deploy (usually 1–2 minutes), the site stays live at **https://czheng987.github.io/UIUX_Portfolio/**.

### Optional: shorter URL

Rename the repository to `ChelsPortfolio` under **Settings → General**, then run:

```bash
git remote set-url origin https://github.com/czheng987/ChelsPortfolio.git
```

The site will move to **https://czheng987.github.io/ChelsPortfolio/**.
